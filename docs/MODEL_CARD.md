## 1. 의도된 용도

퇴원 시점에서 향후 30일 내 비계획 재입원 위험을 계층화함.

- 대상: 성인(18세 이상), 재원 1일 이상, 원내 사망하지 않은 입원 건
- 출력: 0\~1 위험 확률
- 상정 사용처: 퇴원 계획 수립 시 고위험군 선별(추가 추적관찰, 재택간호 연계 등)

### 예측 시점을 퇴원으로 못박은 이유

예측 시점에 따라 쓸 수 있는 정보와 누수가 되는 정보가 갈림.
재원일수(LOS), 재원 중 진단, 재원 중 투약은 퇴원 시점에 알 수 있으므로 사용 가능함.

## 2. 금지 사용례

이 모델을 쓰면 안 되는 경우임.

| 금지 | 이유 |
|---|---|
| 입원 시점 예측에 사용 불가 | LOS 가 그 시점엔 미확정임. 재원일수를 입력으로 쓰는 모델을 입원 시점에 돌리면 누수이자 논리적 불가능 |
| 개인에 대한 진료 결정의 단독 근거로 사용 불가 | 위험 계층화 보조 도구이며, 문헌상 이 태스크의 판별력은 AUROC 0.65\~0.75 수준임 |
| 타 기관 그대로 이식 불가 | 단일 기관(BIDMC) 데이터로 학습했고 외부검증을 하지 않음 |
| 보험 심사, 자원 배분 등 환자에게 불리해질 수 있는 용도 불가 | 서브그룹 감사에서 연령, 보험, 입원유형 축의 판별력 격차와 교정 후 확률 어긋남이 확인됨(6절) |
| `has_cxr` 를 임상 근거로 해석 불가 | 아래 5절 참조: 이 변수는 "환자 상태"가 아니라 "의사의 오더 행위"를 반영함 |

### 코호트 구성 (참여자 흐름)

| 단계 | 입원 | 환자 |
|---|---|---|
| 원본 admissions | 546,028 | 223,452 |
| 퇴원≤입원 오류 제거 (180건) | 545,848 | 223,380 |
| 재원 1일 이상 | 425,216 | 186,103 |
| 원내 사망 제외 | 415,231 | 181,595 |

원내 사망을 제외하는 이유: 사망하면 재입원이 물리적으로 불가능하므로,
남겨두면 "재입원 안 함"으로 잡혀 음성 라벨이 오염됨.

### 라벨 정의와 그 한계

MIMIC-IV 에는 30일 재입원 라벨이 없어 직접 계산함.
0 <= (다음 입원의 `admittime`) − (현재 입원의 `dischtime`) < 30일 -> 양성

다음 입원이 현재 퇴원보다 먼저 시작한 겹친 입원(간격이 음수, 주 분석 코호트 34건)은 양성으로 세지 않음.

재입원률은 기준에 따라 크게 달라짐:

| 기준 | 재입원률 |
|---|---|
| 절단 포함, 예정 미제외 (문헌 방식) | 20.73% |
| 절단 포함, 예정 제외 (주 분석) | 19.15% |
| 절단 제외, 예정 미제외 | 33.92% |
| 절단 제외, 예정 제외 | 31.33% |

다음 입원은 코호트 필터를 거치지 않은 전체 입원에서 찾음. 퇴원 뒤 30일 안의 짧은
입원이나 원내 사망으로 끝난 재입원도 재입원임(트러블슈팅 24번).

CMS 정의와는 다름. 관찰 입원도 재입원으로 세고(양성의 40.7%), 다른 급성기 병원 전원
(0.52%)과 자의 퇴원(0.62%)을 index 에서 빼지 않음. 단일 병원 자료라 다른 병원으로의
재입원은 보이지 않음. 표는 docs/report.md 의 "라벨 정의. CMS 재입원 정의와 다른 점"에 있음.

CMS 식으로 바꾼 라벨(관찰 입원을 index 와 재입원에서 빼고 전원, 자의 퇴원 index 와 당일 재입원을 뺀 것)로 다시 재면
index 279,388건, 재입원율 13.26%, Phase 1 test AUROC 0.7237 임. 영상 기여는 파인튜닝 CNN −0.0077, RAD-DINO +0.0023 으로
여전히 판정선(+0.02)에 못 미침. 결론은 라벨 정의에 기대지 않음(report "CMS식 라벨 민감도",
`outputs/label_sensitivity_cms.json`).

우측 절단(right censoring): 각 환자의 마지막 입원은 다음 기록이 없어 무조건 음성이 됨.
전체의 38.9% 가 여기 해당함. "재입원하지 않았다"와 "관찰이 끝나 보이지 않는다"는
다른 사건이지만, MIMIC-IV 는 환자별 날짜 시프트로 전역 관찰 종료일을 알 수 없어
절단 시점을 특정할 수 없음.

어느 한 쪽이 정답이 아니므로 민감도 분석으로 양쪽을 함께 보고함.

## 5. `has_cxr`: 해석에 특별한 주의가 필요한 변수

Phase 1.5 에서 영상 결측이 무작위가 아님(MNAR) 을 확인함.

| | |
|---|---|
| 재원 중 CXR 보유 입원 | 8.6% (35,601 / 415,231) |
| 영상 있음 재입원률 | 24.93% |
| 영상 없음 재입원률 | 18.61% |
| 조 위험비 (crude RR) | 1.340 (95% CI 1.314 \~ 1.366) |
| 재원일수 보정 RR (Mantel-Haenszel) | 1.202 (환자 단위 95% 구간 1.174 \~ 1.228) |
| 점이연 상관 r | 0.045 |

### 교란 보정: 조 RR 을 그대로 보고하면 과장이 됨

재원일수는 `has_cxr` 과 결과 양쪽에 연결되는 교란변수임.
재원이 길수록 영상을 찍을 확률이 오르고(3.7% -> 16.1%), 동시에 더 아파서 재입원 위험도 오름.

| 재원일수 4분위 | n | CXR률 | RR | 95% CI |
|---|---|---|---|---|
| Q1 (단기) | 103,822 | 3.7% | 1.177 | 1.098 \~ 1.261 |
| Q2 | 103,828 | 5.2% | 1.190 | 1.125 \~ 1.259 |
| Q3 | 103,780 | 9.3% | 1.207 | 1.162 \~ 1.254 |
| Q4 (장기) | 103,801 | 16.1% | 1.206 | 1.175 \~ 1.239 |
| MH 요약 | | | 1.202 | 1.174 \~ 1.228 (환자 단위 부트스트랩. 층별 구간은 입원을 독립으로 본 값) |

보정 후에도 연관은 유지됨: 4개 층 전부 RR 1.18\~1.21 로 일관되고,
모든 층의 신뢰구간이 1 을 제외함. 특정 층이 끌어올린 결과가 아님.

따라서 조 RR(1.340) 대신 보정 RR(1.202)을 주 수치로 보고함.

해석할 때 주의할 점: `has_cxr` 가 성능을 올린다면 그것은 "영상의 내용"이 아니라
"의사가 영상을 오더한 행위"를 학습한 것임. 오더 자체가 "이 환자가 더 아프다"는
임상 판단의 대리 지표임.

- 예측 시점(퇴원)에 알 수 있는 정보이므로 기술적으로는 사용 가능함.
- 그러나 병원마다 오더 관행이 다르면 일반화되지 않음.
- 따라서 이 변수를 넣은 모델과 뺀 모델을 모두 보고함.

> 방법론 주의 2건
> 1. 점이연 상관 `r=0.045` 만 보면 "연관 없음"으로 오판함.
>    두 집단이 8.6% vs 91.4% 로 극단적으로 불균형하면 r 이 구조적으로 축소됨.
> 2. 조 RR 만 보면 연관을 과장함. 재원일수 보정 시 1.340 -> 1.202 로 0.138 감소함.
>
> 그래서 상관, 조 RR, 보정 RR 을 함께 보고함.

## 6. 성능

전부 test 집합 실측임. 탐색은 val 로만 함.

해석 기준은 문헌의 AUROC 다(LACE 0.61, 로지스틱 회귀 0.62, 머신러닝 0.65\~0.75, 표는 report 성능 기대치).
0.85 이상이면 누수를 먼저 의심함. 이 저장소에서 퇴원처, 마지막 입원 여부 같은 아홉 컬럼을 넣으면
0.7011 이 0.8271 이 됨.

### 주 모델 (EHR 단독, XGBoost, 전체 코호트)

| 지표 | 값 |
|---|---:|
| n (test) | 83,163 (양성 16,041, 양성률 0.1929) |
| AUROC | 0.7011 |
| PR-AUC | 0.3789 (기준선 0.1929) |
| Brier | 0.2170 |
| ECE (원본 확률) | 0.2687 |
| ECE (Isotonic 보정 후) | 0.0046 |
| EER | 0.3513 |

원본 확률은 확률로 읽으면 안 됨. 불균형 보정(`scale_pos_weight`)이 예측값을
위로 밀어 ECE 가 0.27 임. 교정 방식은 val 을 환자 단위 5겹으로 나눠 밖 겹 예측의
ECE 로 골랐고(Isotonic), test 에서 0.0046 까지 내려감. 순위는 거의 보존됨
(AUROC 0.7011 -> 0.7003). 순위를 한 칸도 바꾸지 않아야 하면 Platt(ECE 0.0051)을 쓰면 됨.
아래 서브그룹 표는 전부 보정 후 값임.

EER 0.3513 은 놓치는 비율과 잘못 부르는 비율이 같아지는 지점의 오류율임.
임계값을 고르지 않고도 판별력을 하나의 숫자로 보기 위한 값이며, 두 오류에 같은
비중을 두므로 운영점이 아님. 운영점은 아래 결정곡선 항목에서 따로 정함.

### 영상 관련 (CXR 보유 부분집합, n=7,168)

| 모델 | test AUROC | PR-AUC | 자세 기준선 대비 |
|---|---:|---:|---:|
| 자세 기준선(픽셀 없이 ViewPosition) | 0.5103 | 0.2554 | 없음 |
| EfficientNet-B0 (절제 승자 = 기준선 설정, 3시드 평균) | 0.5581 +/- 0.0051 | 0.2979 +/- 0.0030 | +0.0477 +/- 0.0051 |
| RAD-DINO 동결 특징 | 0.5853 | 0.3265 | +0.0749 |
| 같은 부분집합 EHR | 0.6613 | 0.3944 | 없음 |

영상은 촬영 자세 기준선을 넘는 신호를 담고 있음. 자세에 촬영 시각까지 더한 촬영 메타데이터는 동결 RAD-DINO 만
판정선(+0.02) 이상으로 넘고, 파인튜닝 CNN 은 +0.0120 으로 판정선에 못 미침(V3). 그러나 EHR 에 더하면
늘지 않음. 파인튜닝 CNN 은 세 융합 방식(이어붙이기, 원본, 후기) 모두 EHR 단독보다 낮고
(최고 −0.0153), 동결 RAD-DINO 도 최고 +0.0014 로 판정선(+0.02)에 못 미침. 쓸모가 없어서라기보다 EHR 과 정보가 겹치는 것으로 보이고, 겹치는 특징을
더하면 오히려 나빠짐.

> 이 표는 한 번 뒤집힌 결론임. 처음에는 DenseNet121 로 0.5037 을 얻어
> "영상은 자세만 본다"고 적음. 그 모델은 학습이 실패한 상태였음(best epoch 1,
> train loss 6에폭 동안 0.008 하락). 백본을 바꾸고 흉부X선 파운데이션 모델로
> 다시 재서 판정이 뒤집힘. 같은 설정으로 제대로 학습한 지금의 DenseNet121 은
> 0.5442 로 "판단 보류"임(`outputs/phase2_metrics.json`).

- 80세 이상에서 AUROC 0.6344 로, 44세 이하(0.7529)보다 0.1185 낮음.
  고령일수록 판별력이 떨어짐.
- 전체 ECE 는 0.0046 인데 집단 간 격차는 최대 0.0922 까지 벌어짐
  (보험 축, No charge n=70 이 0.0990). 표본이 작아 추정이 불안정한 탓이 크지만,
  전체 보정이 좋아도 집단마다 좋은 것은 아님.

CXR 모델의 성별 분해는 확인 실행 3시드에서 여 0.5530 +/- 0.0044 / 남 0.5633 +/- 0.0077
다. 시드 간 변동이 성별 차이만큼 크므로 이 축에서 차이를 주장하지 않음.

| 마지막 입원 38.9% | 측정 불가 | 우측 절단, 7절-2 |

### 임상적 유용성 (결정곡선)

임계값 0.06 \~ 0.50 구간에서 "전원 개입", "전원 미개입"보다 순이익이 높음.
운영점을 알림 10% 로 잡으면 PPV 0.4538(무작위 0.1929 대비 2.35배), 민감도 0.2353 임.
재입원의 3/4 는 놓침. 운영점을 고를 때는 두 숫자를 함께 봄.

### 모델을 바꿔도 결론은 그대로

XGBoost 깊이, 정규화를 바꾼 5종의 AUROC 폭이 0.0127 임. 판정이 특정 모델
설정에 기대고 있지 않음.

## 7. 알려진 한계

1. 단일 기관: BIDMC 데이터만 사용. 외부검증 미수행.
2. 우측 절단 38.9%: 마지막 입원의 결과를 관찰할 수 없음(3절). 다른 병원으로의
   재입원도 보이지 않아 양성이 적게 잡힘. 관찰 입원을 재입원으로 세는 점은 CMS 와 다름(3절).
3. 행 단위 과대대표: 주 분석 코호트(415,231건)에서 환자당 입원 수가 평균 2.29, 최대 95회이고
   상위 1% 환자가 입원의 9.9% 를 차지해 다빈도 입원 환자가 과대대표됨(필터 전 전체 입원에서는
   평균 2.44, 최대 238회, 상위 1% 가 10.9%. `outputs/admission_profile.json`).
   환자 단위 분할로 누수는 막았으나 가중치 보정은 하지 않음.
4. 약물 매칭이 단순함: 약물명 문자열 정규식이라 오탈자, 상품명, 복합제를 놓침.
   RxNorm 등 표준 사전 매핑이 정석임.
5. `admit_year` 사용 불가: 날짜 시프트로 절대 연도에 의미가 없음.
   시간 분할 검증(V7)도 `anchor_year_group` 으로 해야 함.
6. Charlson 은 Quan 2005 매핑 그대로임: mimic-code 의 `charlson` 과 코호트 415,231건에서 항목별로
   대조함. 17항목 중 14항목이 100% 같고, 경증 간, 합병증 없는 당뇨, 암은 표시 방식만 다름(이 저장소는 중증이
   있으면 경증 표시를 0 으로 두고, 공식 표는 점수에서만 큰 쪽을 씀). 점수는 공식 점수에서 나이 점수를 뺀 값과
   415,203건이 같고, 남은 28건은 Quan 2005 뒤에 생긴 ICD-10-CM 암 코드(C4A, C7A, C7B)가 공식 쪽에서만 잡힌 것임.
   유병률은 전체 입원 546,028건에서 COPD 18.4% / 신질환 15.8% / 심부전 15.5% / 전이암 5.1%,
   코호트에서는 20.2% / 17.9% / 17.7% / 5.8% 다(트러블슈팅 25).
7. 고령에서 판별력이 떨어짐: 80세 이상 AUROC 0.6344 로 44세 이하(0.7529)보다
   0.1185 낮음. 이 모델을 고령 병동에
   그대로 적용하면 전체 성능에서 기대한 것보다 못함.
8. 전체 보정이 집단별 보정을 보장하지 않음: 전체 ECE 0.0046 인데 집단 간
   최대 격차가 0.0922 다(보험 축, No charge n=70 이 0.0990). 표본이 작은 탓이 크지만, 집단별
   재보정 없이 확률을 쓰면 특정 집단에서 어긋남.
9. 절제실험의 설정 비교는 시드 하나로 함: 여덟 설정 모두 seed 42 이고 시드 반복은 기준선에만
   함. 기준선을 넘은 설정이 없어 승자는 기준선이고, 가장 가까운 설정(weight decay 1e-3)은
   −0.0001 임. 기준선을 시드만 바꾼 폭(val PR-AUC 표준편차 0.0093)이 설정 차이 대부분과 같은
   크기라, 설정 사이의 순위는 주장하지 않음. 분할 변동은 재지 않았고 보통 그쪽이 더 큼.
10. 확인 실행의 표준편차는 초기화 변동만 담음: 분할 시드를 42 로 고정함.
    분할까지 바꾸면 앞 실행의 val 환자가 뒤 실행의 test 로 들어가기 때문임.
    보고된 +/- 0.0051(test AUROC)은 잡음의 하한이지 전체가 아님. 이 폭 때문에
    EfficientNet-B0 의 "영상을 봤다"(시드 42, +0.0534)는 세 시드 평균(+0.0477)으로 "판단 보류"가 됨.

## 8. 비식별화 검증

배포본의 비식별화를 직접 검사함. 검증 결과 7/7 통과 (영상 500장 표본).

| 검사 | 결과 |
|---|---|
| 배포 메타데이터 5종 PHI 컬럼 | 통과 |
| 날짜 시프트 일관성 (CXR 와 EHR) | 통과 (겹침률 51.4% -> 동일 오프셋 확인) |
| EXIF 메타데이터 | 통과 (0장에 EXIF) |

### 통과/실패로 가를 수 없는 관찰

| 관찰 | 수치 | 해석 |
|---|---|---|
| 모서리에 새겨진 텍스트 | 500장 중 259장 (51.8%) | 눈으로 확인한 표본에서는 전부 `R`/`L` 자세 마커, `PORTABLE`, `semi upright` 촬영기법 주석, 방향 화살표였음. PHI 아님 |
| 마스킹 흔적 (내부 검정 사각형) | 500장 중 64장 (12.8%) | 배포자가 픽셀을 가린 자국: 비식별화가 실제로 적용됐다는 증거 |

"텍스트가 있다"를 실패로 판정하지 않는 이유. 처음 구현은 모서리의 포화 픽셀
비율(≥0.4%)로 판정했고 400장 중 93%가 의심으로 걸려 검증 전체가 FAIL 이었음.
흉부 X선 모서리는 콜리메이션 경계, 흰 여백 때문에 원래 포화돼 있어(중앙값 3.7%),
임계를 20%로 올려도 9%가 남음. 비율로는 "흰 테두리"와 "글자"를 가를 수 없음.
지금은 글자의 기하 구조(읽을 수 있는 크기, 통짜 아님, 같은 줄 정렬 2자 이상)로
탐지하되, 내용을 읽지 못하므로 PHI 여부는 판정하지 않고 관찰로만 남김.

### 검증할 수 없는 것 (명시)

DICOM PS3.15 De-identification Profile 은 DICOM 태그를 전제함.
이 프로젝트는 MIMIC-CXR-JPG(이미 변환, 비식별화된 배포본)를 쓰므로 다음은
검증 대상이 존재하지 않음:

- PHI 태그 (PatientName / PatientID / AccessionNumber 등)
- UID 재매핑 (StudyInstanceUID / SeriesInstanceUID / SOPInstanceUID)
- 벤더 private tag 은닉 정보
- `BurnedInAnnotation` 태그값 -> 픽셀 검사로 대체

그러나 burned-in annotation 검사는 JPG 에서도 필요함.
태그를 다 지워도 픽셀에 새겨진 이름, ID, 검사일은 남고, JPG 변환은 이를 제거하지 않음.

한계: 컬럼명 기반 PHI 검사는 값 수준 식별자를 잡지 못함.
새겨진 텍스트 탐지는 OCR 이 아니라 기하 휴리스틱이라 내용을 읽지 못함:
따라서 그 텍스트가 PHI 인지 아닌지는 이 절차로 판정할 수 없음. 어두운 배경에
어두운 글자로 새겨진 주석은 포화되지 않아 놓침.
확정 판정이 아니라 사람이 확인할 후보를 좁히는 용도임.

영상 무결성은 별도로 확인함: 내려받은 35,599장 전량에 대해 JPEG 마커
검사와 전체 디코딩을 모두 수행했고 없음, 0바이트, 잘림, 손상 0건임
(`python scripts/verify_cxr.py --deep`).

## 9. 윤리적 고려

- 공정성 감사: 성별, 연령대, 보험, 입원유형 네 축으로 교정 전후 모두 함(6절). 인종 축은 하지 않음.
- 잠재적 해악: 고위험으로 잘못 분류되면 불필요한 개입이, 저위험으로 잘못 분류되면
  필요한 추적관찰이 누락됨. 임계값 선택이 이 균형을 결정하므로
  순이익(net benefit) 기준 임상 유용 구간을 0.06\~0.50 으로 특정함(6절).
- 데이터 거버넌스: 데이터와 파생물은 공개 저장소에 재배포하지 않음.
  코드, 재현 스크립트만 공개하며, 유출 차단을 3중으로 둠
  (`.gitignore` + pre-commit 훅 + 실험 추적 백엔드 화이트리스트): 상세는 8절 끝.
