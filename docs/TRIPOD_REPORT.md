## Part 2. Introduction

### 3. Background

30일 재입원은 CMS HRRP(Hospital Readmissions Reduction Program)의 핵심 품질 지표로,
병원에 재정적 불이익이 연동됨. 퇴원 시점에 고위험군을 선별하면 추가 추적관찰,
재택간호 연계 등으로 개입할 여지가 생김.

기존 도구인 LACE index 는 AUROC 0.61 수준이며, 머신러닝을 써도 문헌상
0.65 \~ 0.75 에 머묾.

### 4. Objectives

1. EHR 단독 베이스라인을 문헌 수준으로 재현함.
2. 흉부 X선을 더했을 때 실제로 이득이 있는가를 분해 측정함.
3. 그 성능 수치가 믿을 만한가를 검증함: 누수, 보정, 서브그룹, 시간 일반화.

이 프로젝트의 목적은 성능을 올리는 것보다 "이 숫자를 믿어도 되는가"에 답하는 것임.

### 8. Outcome

All-cause unplanned readmission within 30 days. CMS 의 정의를 바탕으로 했고, 다른 점은
이 절 끝의 표에 모음.

0 <= (다음 입원의 `admittime`) − (현재 입원의 `dischtime`) < 30일 -> 양성. 다음 입원이 현재 퇴원보다 먼저 시작한 겹친 입원(간격이 음수, 주 분석 코호트 34건)은 양성으로 세지 않음.

다음 입원은 6절의 포함, 제외 기준을 거치지 않은 전체 admissions 에서 찾음. 기준은
index 입원의 조건이지 재입원의 조건이 아님. 하루를 못 채운 재입원이나 원내 사망으로
끝난 재입원도 양성임.

예정 재입원(`ELECTIVE`, `SURGICAL SAME DAY ADMISSION`)은 outcome 에서 제외함.
단 index 로는 사용함.

> "계획된 재입원"을 가려내는 방식은 CMS 와 다름. CMS 는 Planned Readmission
> Algorithm 을 씀. 시술, 진단 코드로 판정하며, 장기이식, 분만, 유지 항암/면역치료,
> 재활은 항상 계획으로 보고 급성 질환이나 치료 합병증은 절대 계획으로 보지 않음.
> 여기서는 MIMIC-IV 의 `admission_type` 두 값으로 근사함. 근사라서 양쪽으로
> 틀림. 응급으로 기록된 계획 시술은 못 걸러내고, 계획이 아닌 예정 입원까지
> 빼 버림. 재입원률이 기준에 따라 20.73% 와 19.15% 로 갈리는 것이 이 선택의
> 크기임(아래 표). 코드 기반 알고리즘을 옮기지 않은 것은 MIMIC-IV 의 시술 코드
> 매핑을 따로 검증해야 해서이고, 하지 않았다는 사실을 26절-13 에 남김.

우측 절단: 각 환자의 마지막 입원(전체의 38.9%)은 다음 기록이 없어 무조건 음성이 됨.
MIMIC-IV 는 날짜 시프트로 전역 관찰 종료일을 알 수 없어 절단 시점을 특정할 수 없음.

재입원률은 기준에 따라 크게 달라짐:

| 기준 | 재입원률 |
|---|---|
| 절단 포함, 예정 미제외 | 20.73% <- 선행연구 방식 |
| 절단 포함, 예정 제외 (주 분석) | 19.15% |
| 절단 제외, 예정 미제외 | 33.92% |
| 절단 제외, 예정 제외 | 31.33% |

선행연구가 보고한 415,231건과 입원 수가 같음. 재입원률은 선행연구의 약 18% 보다
높은데, 다음 입원을 필터 뒤 코호트가 아니라 전체 입원에서 찾기 때문임(코호트
안에서만 찾으면 18.01%). 두 방식 모두 절단된 입원을 전부 음성으로 처리함.

CMS 정의와 다른 점. 기준은 CMS 병원 전체 재입원 측정(HWR)의 방법론 보고서
(Horwitz 등, Yale CORE, 2011)임.

| 항목 | CMS 병원 전체 재입원 측정(HWR) | 이 저장소 | 크기(주 분석 코호트 415,231건) |
|---|---|---|---|
| 재입원으로 세는 입원 | 급성기 병원의 inpatient 입원 | `admissions` 의 모든 입원(관찰 입원 포함) | 양성 79,509건 중 다음 입원이 관찰 입원 32,357건(40.7%) |
| index 에서 빼는 입원 | 원내 사망, 다른 급성기 병원 전원, 자의 퇴원, 재활 입원 | 원내 사망(사망 시각 또는 `hospital_expire_flag`)만 | 전원 2,144건(0.52%), 자의 퇴원 2,588건(0.62%)이 남아 있음 |
| 대상 | 65세 이상 Medicare | 18세 이상 전체 | 없음 |
| 계획 재입원 | Planned Readmission Algorithm(시술, 진단 코드) | `admission_type` 두 값으로 근사 | 재입원률 20.73% 대 19.15% |
| 재입원을 보는 범위 | 모든 병원 | BIDMC 한 병원 | 다른 병원으로의 재입원은 보이지 않아 양성이 적게 잡힘 |

### 9. Predictors

예측 시점 = 퇴원. 예측 시점에 따라 쓸 수 있는 정보와 누수가 되는 정보가 갈림.

| 군 | 변수 |
|---|---|
| 인구학 | 나이(상한 처리 플래그), 성별 |
| 입원 | 재원일수(원값, 로그), 응급 여부, 예정 여부, 응급실 경유, 체류시간, 주말 퇴원, 월/요일 |
| 동반질환 | Charlson Comorbidity Index (Quan 2005 ICD-9/10) + 개별 17종 |
| 이용 | 진단 수, 시술 수, 최근 12개월 입원 횟수 |
| 투약 | 총 종수, 다약제(5종 이상), 고위험 6계열 |
| 영상 | `has_cxr`, 촬영 횟수, AP 여부, 마지막 촬영\~퇴원 간격 |

최근 12개월 입원 횟수는 현재 입원 시각 t 에서 [t - 365.28일, t) 에 시작한 입원 수임(12 x 30.44일, 현재 입원 제외, 코호트 필터 전 전체 admissions 에서 셈).

누수 차단: 결과를 알려주는 변수는 자동 제외함
(`is_last_admission`, `discharge_location`, `days_to_next_admission`, `admit_year_shifted`).

### 10. Sample size

사전 표본수 산정을 하지 않음. 가용한 전체 코호트를 사용함(415,231건).
다만 서브그룹 분석에는 최소 표본수 기준(n≥50) 을 두고, 미달 그룹은 경고를 붙임.

### 11. Missing data

| 항목 | 처리 |
|---|---|
| 원천 테이블 부재 | 해당 피처를 생성하되 전부 결측이면 모델 입력에서 제외 |
| 응급실 미경유 | `ed_hours=0`, `via_ed=0`: 결측이 아니라 '해당 없음' |
| 영상 없음 | `has_cxr=0`. `hours_cxr_before_discharge` 는 NaN 유지(0으로 채우면 의미 왜곡) |
| 영상 결측의 성격 | MNAR: 아래 참조 |

#### 영상 결측은 무작위가 아님(MNAR)

| | |
|---|---|
| 재원 중 CXR 보유 | 8.6% (35,601 / 415,231) |
| 영상 있음 재입원률 | 24.93% |
| 영상 없음 재입원률 | 18.61% |
| 조 위험비 (crude RR) | 1.340 (95% CI 1.314 \~ 1.366) |
| 재원일수 보정 RR (MH) | 1.202 (환자 단위 95% 구간 1.174 \~ 1.228) |
| 점이연 상관 r | 0.045 |

교란 보정: 재원일수는 `has_cxr` 과 결과 양쪽에 연결되는 교란변수임
(재원 길수록 촬영률 3.7%->16.1%, 동시에 재입원 위험도 상승).

| 재원일수 4분위 | RR | 95% CI |
|---|---|---|
| Q1 (단기) | 1.177 | 1.098 \~ 1.261 |
| Q2 | 1.190 | 1.125 \~ 1.259 |
| Q3 | 1.207 | 1.162 \~ 1.254 |
| Q4 (장기) | 1.206 | 1.175 \~ 1.239 |
| MH 요약 | 1.202 | 1.174 \~ 1.228 (환자 단위 부트스트랩. 층별 구간은 입원을 독립으로 본 값) |

보정 후에도 4개 층 전부 CI 가 1 을 제외해 연관은 유지됨.
주 수치로는 조 RR 이 아니라 보정 RR 1.202 를 보고함.

> 방법론 주의 2건
> 1. 두 집단이 8.6% vs 91.4% 로 불균형하면 점이연 상관이 구조적으로 축소됨.
>    `r=0.045` 만 보면 "연관 없음"으로 오판함.
> 2. 조 RR 만 보면 과장함(1.340 -> 보정 1.202).
>
> 그래서 상관, 조 RR, 보정 RR 을 함께 보고함.

해석할 때 주의할 점: `has_cxr` 는 "영상의 내용"이 아니라 "의사가 영상을 오더한 행위"를
반영함. 오더 자체가 임상 판단의 대리 지표이며, 병원마다 관행이 다르면 일반화되지 않음.

### 12. Analytical methods

| | |
|---|---|
| 정형 모델 | XGBoost (`eval_metric=aucpr`, 불균형 대응 `scale_pos_weight`) |
| 영상 모델 | DenseNet121 / ResNet50 / EfficientNet-B0, 2단계 파인튜닝, AMP |
| 분할 | 환자 단위(`subject_id`) train/val/test. 위반 시 `LeakageError` 예외 |
| 모델 선택 | val 기준. test 는 1회만 평가 |
| 실험 추적 | MLflow 로컬 sqlite. git 저장소 안에서 돌리면 커밋 해시와 dirty 여부를 기록하지만, 이 결과는 git 저장소를 만들기 전에 돌려 커밋이 모두 `unknown` 임(report 설계 원칙 4번) |
| 다중 비교 | MNAR 진단의 상관 검정 3개에 Bonferroni 보정(`p_bonferroni`) |

서브그룹 비교(성별, 연령대, 보험, 입원유형)에는 검정을 쓰지 않음. 대신 사전에 정한
판정선으로 가름. 네 축에 검정을 돌리면 다중 비교가 되고, 표본이 큰 쪽에서는
임상적으로 의미 없는 차이도 유의해지기 때문임. 판정선은 결과를 보기 전에
`scripts/run_phase4.py` 머리에 고정한 관례적 값임(집단 간 AUROC 격차 0.05, ECE 0.05).

### 13. Class imbalance

리샘플링(SMOTE 등)은 쓰지 않음. 불균형은 손실의 가중치로만 다룸.

| 모델 | 방법 | 값 |
|---|---|---|
| 정형(XGBoost) | `scale_pos_weight` = train 음성 수 / 양성 수 | 4.2206 (Phase 1) |
| 영상(CNN) | `BCEWithLogitsLoss` 의 `pos_weight` | 3.0534 (DenseNet121) |

가중치는 판별력을 지키는 대신 출력 확률을 위로 밂. 원본 ECE 가 0.2687 인 이유가 이것이고,
그래서 val 로 맞춘 Isotonic 교정을 거친 확률만 확률로 읽음(15절, 23절).

### 14. Fairness

서브그룹 감사를 성별, 연령대, 보험, 입원유형 네 축으로 함. 축마다 집단 간 AUROC 최대
격차와 ECE 최대 격차를 교정 전후로 재고, 사전에 정한 판정선으로 "차이 있음/없음"을 가름.
n 이 50 미만인 집단은 경고를 붙임(`MIN_SUBGROUP_N`). 결과는 23절의 서브그룹 표에 있음.
인종과 촬영 자세 축은 하지 않음(26절-12).

### 15. Model output

모델의 출력은 30일 재입원 확률 하나임. XGBoost 의 원본 출력은 가중된 점수라서 val 로 맞춘
Isotonic 교정기를 거친 값을 확률로 씀. 운영에서는 이 확률로 순위를 매겨 상위 일정 비율에
알림을 주는 방식을 상정함(알림 10% 의 운영점은 27절). 결정곡선은 교정된 확률로 그림.

### 16. Training versus evaluation

| 셋 | 쓰임 |
|---|---|
| train (환자 단위 70%) | 모델 적합 |
| val (환자 단위 10%) | 모델 선택, 교정기 적합과 교정 방식 선택(val 을 환자 단위 5겹으로 나눈 밖 겹 ECE), RAD-DINO 뒷단 선택, 절제실험 판정 |
| test (환자 단위 20%) | 최종 평가 한 번 |

분할은 `subject_id` 단위이고 겹치면 `LeakageError` 로 멈춤. 영상 부분집합과 Phase 3 이후는
인코더가 학습한 분할을 그대로 물려받아, 인코더가 본 환자가 평가로 넘어가지 않게 함. 외부
검증 셋은 없음(26절-1).

- 융합: 영상을 EHR 에 더해도 늘지 않음. 파인튜닝 CNN 은 세 방식 모두

## Part 7. Discussion

### 25. Interpretation

세 가지로 요약됨.

1. 판별력은 문헌 범위 안이고, 그 이상을 노리면 누수를 먼저 의심해야 함.
   누수 컬럼 9개만 넣어도 0.7011 이 0.8271 이 됨.
2. 영상은 신호를 담지만 EHR 에 더해도 늘지 않음. 자세 기준선(0.5103)을
   넘는다는 점에서 픽셀을 읽고 있는 것은 맞음(EfficientNet-B0 3시드 평균 +0.0477, 세 시드 모두
   "자세를 본 것" 선 +0.02 는 넘음, "영상을 봤다" 선 +0.05 는 시드 하나만. RAD-DINO +0.0749).
   자세에 촬영 시각까지 더한 촬영 메타데이터(0.5333)는 동결 RAD-DINO 만 판정선 이상으로 넘고(+0.0438),
   파인튜닝 CNN 은 +0.0120 으로 못 미침(V3).
   그런데 EHR 에 더하면 늘지 않음. 중증도, 과거 입원력 같은 대리지표가 양쪽에
   다 들어 있는 것으로 보임.
3. 원본 출력은 확률로 쓸 수 없었음. ECE 0.2687 은 임계값 운영이 불가능한
   수준임. 보정 후에야 순이익 계산이 의미를 가짐.

시간 이동에는 견딤. 2008\~2019 로 학습해 2020\~2022 를 맞히면 AUROC 0.6819 인데,
같은 크기 무작위 분할 대조군 3회 평균이 0.6999 라 하락폭이 0.0180 임.
촬영 시점(M2)은 인코더에 따라 답이 갈림. 우리가 학습한 CNN 임베딩으로는 표본
크기를 맞춘 뒤 폭이 0.0353 으로 판정선(0.03)을 넘고, 공개 인코더 RAD-DINO 로는
0.0285 로 못 미침. 어느 창이 가장 나은지도 두 인코더가 다름. 창을 어디로 잡느냐가 결과를 바꾼다고 단정할 수 없고, 바꾸지
않는다고도 할 수 없음.

이 값은 한 번 크게 틀렸던 자리임. 예전에는 표본을 맞춘 폭이 0.2596 이라 "창이
결과를 바꾼다"로 적었는데, 그것은 창마다 분할을 새로 만드는 바람에 인코더가
학습한 환자가 평가로 넘어가 생긴 값이었음(트러블슈팅 19번). 분할을 물려받게
고친 지금 값이 위의 0.0353 임.

### 26. Limitations

1. 단일 기관 (BIDMC). 외부검증 미수행.
2. 우측 절단 38.9%, 결과를 관찰할 수 없는 입원이 40% 가까이임.
3. 행 단위 과대대표: 분석 코호트에서 한 환자가 최대 95행(입원)을 차지하고, 상위 1% 환자가 입원의 9.9% 를 차지함(20절).
   환자 단위 분할로 누수는 막았으나 가중치 보정은 하지 않음.
4. 약물 매칭이 단순함: 문자열 정규식. RxNorm 표준 매핑이 정석.
5. `admit_year` 사용 불가: 날짜 시프트. 시간 분할 검증도 `anchor_year_group` 필요.
6. Charlson 은 Quan 2005 매핑 그대로임: mimic-code `charlson` 과 대조해 점수가 415,231건 중 415,203건 같음(나이 점수
   제외). 남은 28건은 Quan 2005 뒤에 생긴 ICD-10-CM 암 코드라 공식 쪽에서만 암으로 잡힘.
7. 원본 확률을 그대로 쓰면 안 됨: `scale_pos_weight` 가 예측값을 위로 밂
   (ECE 0.2687). Isotonic 보정 후 0.0046 으로 내려감. 배포한다면 보정이 선행돼야 함.
8. 고령에서 판별력이 떨어짐: 80세 이상 AUROC 0.6344 로 44세 이하(0.7529)보다
   0.1185 낮음.
9. 전체 보정이 집단별 보정을 보장하지 않음: 전체 ECE 0.0046 인데 집단 간
   최대 격차 0.0922(보험 축, No charge n=70 이 0.0990). 표본 크기 탓이 크지만
   집단별 재보정 없이 확률을 쓰면 특정 집단에서 어긋남.
10. 중증도 대리지표 의존 가능성: SHAP 상위 5개 중 `los_days`, `n_diagnoses`
    두 개가 중증도의 대리지표임. 누수는 아니지만, 모델이 재입원 위험이 아니라
    "얼마나 아팠는가"를 재고 있을 가능성을 배제하지 못함.
11. 절제실험의 설정 비교는 시드 하나: 여덟 설정 모두 seed 42, 시드 반복은 기준선에만 함.
    기준선을 넘은 설정이 없어 승자는 기준선임. 기준선을 시드만 바꾼 폭(val PR-AUC 표준편차 0.0093)이
    설정 차이 대부분과 같은 크기라 설정 사이의 순위는 주장하지 않음. 분할 변동은 재지 않았고 보통 그쪽이
    더 큼. 확인 실행의 +/- 0.0051(test AUROC)도 초기화 변동만 담은 잡음의 하한이며, 이 폭 때문에
    EfficientNet-B0 의 "영상을 봤다"(시드 42)는 세 시드 평균으로 "판단 보류"임.
12. 인종, 촬영자세별 분해 미수행: 성별, 연령, 보험, 입원유형만 함.
13. 계획 재입원 판정이 CMS 와 다름: CMS 의 Planned Readmission Algorithm 은
    시술, 진단 코드로 가르는데, 여기서는 `admission_type` 두 값으로 근사함(8절).
    양쪽으로 틀릴 수 있고 그 크기는 재입원률 20.73% 대 19.15% 의 차이임. 코드 기반
    알고리즘을 쓰려면 MIMIC-IV 의 시술 코드 매핑을 따로 검증해야 함.
14. 관찰 입원을 재입원으로 셈: CMS 는 inpatient 입원만 재입원으로 셈. 여기서는 양성의
    40.7% 가 관찰 입원임. 다른 급성기 병원 전원(0.52%)과 자의 퇴원(0.62%)도 index 에서
    빼지 않음(8절 표). 단일 병원 자료라 다른 병원으로의 재입원은 보이지 않음. 이 셋을 CMS 식으로 바꾼 라벨로
    다시 재도 결론은 같음(index 279,388건, 재입원율 13.26%, AUROC 0.7237, 영상 기여 CNN −0.0077, RAD-DINO +0.0023.
    report "CMS식 라벨 민감도", `outputs/label_sensitivity_cms.json`).

#### 일반화

단일 기관, 단일 기간 데이터이므로 타 기관 이식 가능성은 검증되지 않음.
특히 `has_cxr` 는 오더 관행에 의존하므로 기관 간 이전 가능성이 낮을 수 있음.

### 27. Usability of the model in the context of current care

AUC 는 "잘 구분하나"에만 답하고 "도입하면 이득인가"에는 답하지 않음. 그래서
결정곡선(DCA)으로 순이익을 봄.

임계값 0.06 \~ 0.50 구간에서 "전원 개입", "전원 미개입" 두 기준선보다
순이익이 높음(스캔 범위 0.05\~0.50, 0.05 에서는 "전원 개입"과 거의 같음). 실무에서 쓸 만한 임계값이 이 폭(0.44) 안에 있음.

운영점을 감당 가능한 알림량 10% 로 잡으면(임계값 0.6943):

| 지표 | 값 |
|---|---:|
| 알림 수 | 8,316 / 83,163 |
| PPV | 0.4538 (무작위 0.1929 대비 2.35배) |
| 민감도 | 0.2353 |
| 선별필요수 | 2.20 |

민감도 0.235 를 함께 봐야 함. 알린 10명 중
4\~5명이 실제 재입원이지만, 전체 재입원의 3/4 는 알림을 받지 못함. 이 모델은
"제한된 자원을 어디에 먼저 쓸지"에 답하는 용도이고, 재입원을 놓치지 않게 하는 용도로는 쓸 수 없음.

임상 도입 전 필요한 것: 외부 기관 검증, 고령 집단 별도 검토(26절-8),
집단별 재보정(26절-9), 그리고 개입 자체의 효과 검증. 이 저장소는 예측까지만
답하고 개입 효과는 답하지 않음.
