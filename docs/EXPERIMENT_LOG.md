모든 수치는 val 기준이다. 탐색을 test 로 하면 열 몇 번 돌린 시행들의 운이

## 실험별 경위

### 실험 #1: baseline

- 가설: 기준선. 384px 와 batch 64 를 출발점으로 삼는다
- 바꾼 것: 없음(기준선)
- 결과: val PR-AUC 0.3297 (기준선), best 7에폭 / 실행 15에폭
- 시드별: seed 42 0.3297, seed 43 0.3127, seed 44 0.3145
- 학습 곡선: train loss 1.0508 -> 0.8141, 조기종료 True
- 진단: 정상 수렴(정점 후 하락으로 조기종료)
- 설정: aug=strong lr=0.001/0.0001 wd=0.0001 batch=64 size=384 sched=cosine pos_weight=auto

### 실험 #2: size-224

- 부모 회차: 실험 #1
- 가설: 384px 가 224px 보다 나은지부터 확인한다. 큰 해상도를 쓸 수 있다는 것과 쓸 값어치가 있다는 것은 다르다
- 바꾼 것: size 384 -> 224
- 결과: val PR-AUC 0.3169 (차이 없음 (-0.0129)), best 7에폭 / 실행 15에폭
- 학습 곡선: train loss 1.0533 -> 0.9408, 조기종료 True
- 진단: 정상 수렴(정점 후 하락으로 조기종료)
- 설정: aug=strong lr=0.001/0.0001 wd=0.0001 batch=64 size=224 sched=cosine pos_weight=auto

### 실험 #3: aug-medium

## 여기까지의 결론

- 가장 높았던 회차: 실험 #1 (baseline) val PR-AUC 0.3297
- 기준선보다 나아진 실험: 0건
- 오히려 나빠진 실험: 1건 ['aug-light']
- 판정은 같은 시드(seed 42)인 기준선 한 번 값(0.3297)과 비교했다. 기준선 계열 평균(0.3190)과 비교하면 판정이 달라지는 실험: 1건 aug-light(-0.0163)
- 의무 구간(#1\~5) 이후 연속 미개선: 3회 (3회면 종료)
- 총 8회 실험 + 재현 2회, 누적 5.8시간

## 이 실험의 한계

기준선을 넘은 회차가 없다. 설정을 바꾼 7회는 기준선보다 0.0001\~0.0271 낮았고, 같은 설정을 시드만 바꿨을 때 0.0170 만큼 벌어진다. 가장 가까운 회차도 시드 폭 안이라 설정 차이로 읽지 않고, 기준선 설정을 그대로 확인 실행으로 넘긴다.

이 값은 초기화, 배치순서에서 오는 폭만 담는다. 분할 시드는 42 로 고정했다. 분할까지 바꾸면 앞 실행의 val 환자가 뒤 실행의 test 로 들어가기 때문이다. 즉 실제 변동폭은 이보다 크면 컸지 작지 않다.

증강 강도를 4단계로 재보니 light 0.3027 -> medium 0.3145 -> strong 0.3297 -> extreme 0.3176 로, 오르다 마지막에 꺾이는 모양이 나왔다. 다만 이웃 단계 차이 3개 중 3개가 시드만 바꾼 폭(0.0170) 안이라 이 모양도 우연일 수 있다. 방향만 참고로 남기고 '최적값이 어디다'는 주장은 하지 않는다.

통계 검정은 하지 않았다. 판정선은 검정이 아니라 회차 간 변동폭에서 뽑은 눈금이다. 그 선을 넘었다고 유의하다는 뜻이 아니라, 그보다 작은 차이는 이 실험으로 구분할 수 없다는 뜻이다.
