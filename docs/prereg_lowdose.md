# 사전등록: 흉부 X선 저선량 모사와 복원이 소견 분류에 주는 영향

결과를 보기 전에 쓴다. 이 문서의 판정 규칙은 결과를 본 뒤 바꾸지 않는다. 바꿀 일이 생기면
맨 아래 "수정 이력"에 날짜, 이유와 함께 적고 원래 문장은 지우지 않는다.

## 1. 질문

1. 선량을 줄인 것처럼 잡음을 넣으면, 공개 흉부 X선 파운데이션 모델(RAD-DINO) 특징으로 가린 소견 분류 AUROC 가 떨어지는가.
2. 떨어진다면 잡음 제거(복원)가 그 하락을 얼마나 되찾는가.
3. 복원 없이 분류기를 저선량 영상으로 다시 학습하는 것보다 복원이 나은가.
4. 화질 지표(PSNR, SSIM)가 오르는 것과 분류 AUROC 가 오르는 것이 같은 방향인가.

재입원 예측(이 저장소의 본 과제)과는 별개의 부가 분석이다. 재입원 라벨은 영상 신호가 약해(AUROC 0.56\~0.59) 화질의
영향을 재기 어려우므로, 영상 소견 라벨을 쓴다.

## 2. 자료

- 영상: 서버에 받아 둔 MIMIC-CXR-JPG 41,695장 중 정면(ViewPosition 이 PA 또는 AP) 33,683장, 환자 22,763명.
  8비트 흑백 JPG, 긴 변 1,500\~3,000px.
- 라벨: `mimic-cxr-2.0.0-chexpert.csv.gz`(study 단위). 소견 다섯: 흉수(Pleural Effusion), 심비대(Cardiomegaly),
  폐부종(Edema), 무기폐(Atelectasis), 기흉(Pneumothorax). 1 은 양성, 0 과 빈칸은 음성(빈칸은 "언급 없음"),
  불확실(-1)은 그 소견의 분석에서 뺀다(U-Ignore). 민감도로 불확실을 음성으로 둔 경우(U-Zeros)를 함께 적는다.
- 분할: 기존 `src/splits.patient_split`(seed 42, test 0.2, val 0.1)을 정면 영상의 subject_id 에 적용한다.
  세어 둔 값은 train 23,427장, val 3,389장, test 6,867장(환자 4,553명). test 양성은 흉수 1,939, 심비대 1,951, 폐부종 882,
  무기폐 1,707, 기흉 269 로 모두 100 을 넘는다.
- 특징 추출기 RAD-DINO 는 라벨 없이 자가지도로 학습된 공개 모델이라 이 분할과 우리 라벨을 보지 않았다. 다만 사전학습
  자료에 MIMIC-CXR 영상이 들어 있다(Phase 2-C 와 같은 한계).

## 3. 저선량 모사

표시 영상을 검출기 원시 자료로 되돌릴 수 없으므로 아래는 근사다. 가정을 모두 적는다.

1. 픽셀값 v(0\~255)를 감쇠 선적분 p = k v / 255 로 본다. 밝을수록(뼈, 종격동) 많이 흡수된 곳이다. 주 조건 k = ln(100)
   (가장 밝은 곳의 투과율이 가장 어두운 곳의 1/100). 민감도 k = 3, 6.
2. 원 선량의 기대 광자 수 N = N0 exp(-p). 선량비 r 에서는 이미 있는 잡음을 빼고 모자란 만큼만 더한다
   (Veldkamp 등, J Digit Imaging 2009 의 잡음 삽입 방식). 광자 수 영역에서 r N 에 분산 r N (1 - r) 의 가우시안 잡음을
   더하고 r 로 나눈 뒤 p' = -ln(값 / N0) 로 되돌린다. 광자 수는 1 아래로 내려가지 않게 자른다. 검출기 전자 잡음은 JPG 에서
   잴 방법이 없어 0 으로 둔다(한계).
3. v' = 255 p' / k 를 반올림하고 0\~255 로 자른다.
4. N0 는 train 영상 500장(고정 시드로 고름)의 원본 해상도 잡음 표준편차(웨이블릿 MAD 추정, `skimage.restoration.estimate_sigma`)
   로 정한다. 영상의 평균 밝기에서 모델이 내는 잡음이 잰 잡음과 같아지는 N0 를 영상마다 구하고 그 중앙값을 쓴다.
   민감도 N0 의 0.5배, 2배.
5. 선량비 r = 1/2, 1/4, 1/8. 주 조건은 1/4 이다. 보조 부하 조건으로 1/32 을 val, test 에만 둔다. 원본 해상도에서 넣은
   잡음은 518px 로 줄이면 크게 평균되어, 1/8 까지는 분류에 닿지 않을 수 있다. 어디부터 해치는지 여유를 보려는 것이다.
   1/32 은 DnCNN 학습과 다시 학습한 비교군에 넣지 않으므로, 여기서 DnCNN 은 학습 범위 밖 적용(외삽)이다.
6. 잡음은 원본 해상도에서 넣고, 그 뒤에 RAD-DINO 프로세서와 같은 방식(짧은 변 518 bicubic, 가운데 518 자르기)으로 줄인다.
7. 시드: 영상마다 (dicom_id, 선량비, 조건) 에서 만든 고정 시드. 같은 입력이면 같은 잡음이 나온다.

모사 검증(테스트): 합성 평탄 영상에서 양자화와 축소 전 잡음 표준편차가 r 의 -1/2 제곱에 맞게 커지는지, 밝은 곳의
상대 잡음이 어두운 곳보다 큰지 본다.

## 4. 복원 방법

모두 518px 회색조(0\~1) 영상에서 한다. 분류기가 보는 해상도와 같게 하려는 것이다.

| 방법 | 설정 | 조정 |
|---|---|---|
| 가우시안 | 표준편차 s | val 1,000장의 PSNR 로 선량비마다 s 를 고른다 |
| 비국소 평균 | `skimage.restoration.denoise_nl_means`, h = a 곱하기 추정 잡음 | val PSNR 로 a 를 고른다 |
| BM3D | `bm3d.bm3d`, sigma_psd = b 곱하기 추정 잡음 | val PSNR 로 b 를 고른다 |
| DnCNN | 17층 64채널 잔차 학습, 세 선량비를 섞어 한 모델(blind) | train 영상만 학습, val 손실로 조기종료, 시드 3개 |

추정 잡음은 518px 영상에서 `estimate_sigma` 로 잰 값이다. 조정 격자는 스크립트에 적어 두고 결과를 본 뒤 넓히지 않는다.

## 5. 평가

- 특징: RAD-DINO CLS 토큰(768차원), fp16 추론.
- 주 분류기: 깨끗한 train 특징으로 학습한 소견별 선형 프로브(StandardScaler + LogisticRegression, C = 1.0, max_iter 3000).
  이 분류기 하나를 고정하고 test 영상만 조건별로 바꿔 넣는다.
- 비교군: 선량비마다 저선량 train 특징으로 다시 학습한 프로브를 같은 선량비의 저선량 test 에 적용한다.
- 지표: 소견별 test AUROC 와 다섯 소견 평균. 화질은 518px 에서 깨끗한 영상 대비 PSNR, SSIM(data_range 1).
- 신뢰구간: 환자 단위 짝지은 부트스트랩 1,000회(시드 42), 백분위 95%.
- 층화: AP, PA 로 나눈 평균 AUROC 를 보조로 적는다.

## 6. 판정 (주 지표 하나, 순서대로)

주 지표: 선량비 1/4, DnCNN(시드 3개 평균)에서 다섯 소견 평균 AUROC 의 회복률
회복률 = (복원 AUROC - 저선량 AUROC) / (깨끗한 AUROC - 저선량 AUROC).

1. 하락 확인: 깨끗한 AUROC - 저선량 AUROC 의 95% 신뢰구간이 0 을 포함하면 회복률을 계산하지 않고
   "이 선량비에서는 저선량이 분류를 해치지 않았다"로 적는다.
2. 하락이 있으면 회복률을 적는다. 신뢰구간은 부트스트랩 표본마다 회복률을 계산해 낸다.
3. 복원이 따로 필요한가: 복원(주 분류기) AUROC - 비교군(저선량으로 다시 학습한 분류기) AUROC 의 95% 신뢰구간이 0 보다 크면
   "복원이 낫다", 0 보다 작으면 "다시 학습하는 편이 낫다", 0 을 포함하면 "차이를 확인하지 못했다".
4. 화질과 분류의 방향: 방법, 선량비, 소견 조합마다 PSNR 은 저선량보다 올랐는데 AUROC 는 떨어진 경우를 센다.

나머지(다른 선량비, 다른 방법, 소견별, AP/PA, N0 와 k 민감도, U-Zeros)는 보조 지표다. 보조 지표로 주 판정을 바꾸지 않는다.

## 수정 이력

- val 조정 뒤(test 평가 전), 고전 복원 조정 격자(4절). val 조정 결과(`outputs/lowdose/tune.json`)에서 방법 셋과 선량비 넷의 12건 가운데
  11건이 격자 끝에서 골라졌다. r2, r4, r8 은 가장 약한 끝, r32 의 BM3D 는 가장 센 끝이다. 원인을 val 30장으로 확인했다.
  깨끗한 518px 영상에도 원래 잡음이 있고(추정 0.0049), 518px 에서 더한 잡음은 r2 0.0024, r4 0.0036 으로 그보다 작다.
  고전 방법은 추정 잡음 전체를 지우므로 원래 잡음이 남은 기준 영상과 견준 PSNR 에서 손해를 보고, 약한 쪽 끝이 골라진다.
  r32 는 반대로 추정 잡음(0.0078)이 더한 잡음(0.0113)보다 작아 센 쪽 끝이 골라진다.
  처리: 4절 문장("결과를 본 뒤 넓히지 않는다")대로 원래 격자의 결과를 주 분석으로 그대로 쓴다. 이와 별도로 원래 값을 모두
  포함하고 양쪽으로 넓힌 격자(`TUNE_GRID_WIDE`)로 다시 조정하고 test 에 적용한 결과를 "사전등록 이탈, 보조 분석"으로
  나란히 적는다(산출물 `tune_wide.json`, `classical_wide.json`, 조건 이름 `bm3dwide_r4` 등). 이 결정은 val 조정 결과만
  보고 내렸고 test 의 화질이나 AUROC 는 보지 않았다. 주 지표(r4 DnCNN 회복률)와 판정 순서는 바뀌지 않는다.
- DnCNN 첫 학습 뒤(test AUROC 를 보기 전), DnCNN 학습 설정(4절 표의 "val 손실로 조기종료"는 그대로). 첫 설정(Adam 1e-3 고정, 조기종료 인내 5, 최대
  30에폭)으로 시드 세 개를 학습한 기록(`dncnn_seed*.json`)에서 train 손실이 에폭 사이에 20배까지 튀었고, 시드 2 의 최선
  val 오차(1.34e-5)가 세 선량비 잡음 영상을 그대로 둔 오차(약 1.34e-5)와 같아 사실상 배우지 못했다. 시드 1, 3 도 9\~10에폭에
  멈춰 수렴 전이었다. 학습 설정 결함으로 보고 공개 구현(KAIR train_dncnn.json: Adam 1e-4, 반씩 줄임)과 원 논문(학습률을
  줄여 가며 50에폭)을 따라 Adam 1e-4 시작, val 이 3에폭 멈추면 반으로(최소 1e-6), 인내 10, 최대 60에폭으로 바꾸고 시드 세
  개를 모두 다시 학습한다. 옛 가중치와 복원 영상은 새로 만든 것으로 덮는다. 결정은 train, val 기록으로 내렸다. 점검 중에
  test 300장의 PSNR 을 한 번 봤고(시드 2 의 개선이 거의 없음을 확인), AUROC 는 보지 않았다. 구조, 입력, blind 학습,
  조기종료 기준(val MSE)은 바꾸지 않는다.
